SURPRISE GIFT — GALAXY ELEGANT

Cara pakai:
1. Buka index.html di browser.
2. Kode rahasia default: LOVEYOU
3. Letakkan 3 file MP3 di folder assets:
   - lagu1.mp3
   - lagu2.mp3
   - lagu3.mp3
   Lalu ubah judul/penyanyi/nama file di CONFIG.playlist pada script.js.
4. Foto dapat diganti dengan:
   - assets/foto1.jpg
   - assets/foto2.jpg
   - assets/foto3.jpg
   - assets/foto4.jpg
5. Video yang kamu kirim sudah disertakan sebagai assets/kenangan.mp4.
6. Edit CONFIG di script.js untuk secret code, pesan, penulis, playlist, timeline, dan kata-kata constellation.

Catatan autoplay:
Browser modern sering memblokir autoplay audio dengan suara sebelum ada interaksi pengguna. Project ini mencoba autoplay saat website dibuka, lalu otomatis mencoba lagi pada interaksi pertama (klik/ketukan/keyboard). Setelah musik mulai, satu elemen audio global tetap hidup saat halaman discroll.

Struktur:
- index.html
- style.css
- script.js
- assets/kenangan.mp4
- assets/foto1.jpg ... foto4.jpg (isi sendiri)
- assets/lagu1.mp3 ... lagu3.mp3 (isi sendiri)
